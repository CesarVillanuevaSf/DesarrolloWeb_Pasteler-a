# DesarrolloWeb_Pasteler-a
Desarrollo en la creación de la identidad digital para Pastelería "Flor de Vainilla", transformando un encargo empresarial en una web funcional. Utilicé HTML/CSS para una estructura sólida y JavaScript + 3D para generar una navegación atractiva y moderna.
